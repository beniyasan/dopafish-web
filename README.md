# DOPA Fishing Collection — Web版

iOSアプリ「Dopagaki Fishing Collection」([beniyasan/dopafish](https://github.com/beniyasan/dopafish)) をもとにしたブラウザ版です。
アプリ版を移植したあと、Web版だけの機能(ファイト3種・保留/天井・1日30投・ヌシ・金色個体など)を追加しているため、**現在の抽選・スコア・演出はアプリ版と同じではありません**。

## 遊び方

- **CASTボタン長押し** → 指を離してキャスト(長押し時間でパワー決定)。スペースキー長押しでも可(デスクトップ)
- リーチ中にタイミングよくタップすると**合わせ**が決まり、Lvに応じてファイトが有利になる
- ファイトはレア度で操作が変わる
  - N・R: **連打** / SR・SSR: **長押し**でテンションを緑ゾーンに保つ / UR・LR: 円に重なる瞬間にタップする**リズム**
- **AUTO**で自動連投、**釣具屋**でメダルを使って強化・活き餌の購入
- 釣った魚は**図鑑**に記録される。図鑑をコンプするとエンディングが流れ、シークレット魚が解禁される

## Web版だけの要素

| 要素 | 内容 |
|------|------|
| 保留(先読み) | 次の3投の期待度を色で表示(白→青→緑→赤→金→虹)。途中で色が変わることもある |
| 海の気配(天井) | ハズレ・逃げ・N/Rで溜まり、満タンで次の保留が虹(SSR以上確定)になる |
| 1日30投 | RUSH中の投げは数えない。朝マヅメ/昼/夕マヅメ/夜の時間帯と天気で大物率が変わり、1日の終わりにリザルト(S〜Cランク) |
| デイリーチャレンジ | 日付ごとに同じ抽選になる |
| 活き餌 | 釣ったN/Rを換金せず餌にすると、次の1投の大物率が上がる。釣具屋でも購入可 |
| シークレットの条件 | 図鑑コンプ+金の竿MAXに加えて、夜/霧/雨などの条件で出現 |
| ヌシ | 1投あたり3%で遭遇する持ち越しバトル。1回では倒せず、HPを削って次に持ち越す。3体(岩礁のヌシ・黒鉄鯛 / 沖のヌシ・群青大カジキ / 深淵のヌシ・古代鯨)とも専用イラスト |
| 金色個体 | 1/40で出現し点数3倍。黄金の後光・光の筋・きらめきで表示し、図鑑に記録される |
| サイズ王冠 | その種のサイズ幅の上位5%で獲得し、図鑑に記録される |

## Lolipop Deploy Now 設定

| 項目 | 値 |
|------|-----|
| フレームワーク | `static` |
| output_dir | `/`(リポジトリルート) |

ビルド不要の静的サイト(index.html + js/css + webp画像)です。
魚・ヌシのイラストは `assets/*.webp`(3:2)。

## 技術構成

- Vanilla JS (ES Modules) + Canvas 2D — アプリ版のSpriteKitシーンを2Dキャンバスに移植したもの
- Web Audio API — SE合成 + BGMループ(アプリ版のAudioEngineがベース)
- navigator.vibrate — ハプティクス(対応端末のみ、トグル可)
- localStorage — 図鑑・メダル・最高記録・強化レベル・活き餌・1日の進行・海の気配・ヌシの残りHP・触覚設定を保存

### ゲームロジック(`js/model.js` と `js/model/`)

`GameModel` の本体(状態・時計・投げ〜アタリの流れ)は `js/model.js`、機能ごとのメソッドは `js/model/` に分け、`GameModel.prototype` に取り込んでいます。

| ファイル | 中身 |
|---|---|
| `model/store.js` | localStorage と魚図鑑 |
| `model/shop.js` | 釣具屋(強化)と活き餌 |
| `model/holds.js` | 抽選: 保留(先読み)・天井「海の気配」・レア度の決定 |
| `model/day.js` | 1日(30投)・時間帯・天気・デイリー |
| `model/omens.js` | 予告演出: 連続予告・鳥や魚群・じいさん・リーチの見た目 |
| `model/reach.js` | リーチ: 発展・合わせ |
| `model/fight.js` | ファイト: 連打 / 長押し / ヌシ / リズム / osu! 風 |
| `model/catch.js` | 釣果と結果カード・逃げられたとき・RUSH・通常ED |

### 振る舞いの回帰チェック

```sh
node tools/golden.mjs --check
```

実際の `GameModel` を Node で動かし(乱数・時計を固定、演出はスタブ)、6つのシナリオを自動プレイして、フェーズ遷移・釣果・スコア・RUSH などの列を `tools/golden.expected` と比べます。リファクタで振る舞いが変わっていないことの確認に使います。ゲームの振る舞いを意図して変えたときは `--update` で更新してください。

## デバッグ用URLパラメータ

| パラメータ | 効果 |
|-----------|------|
| `?rig=n\|r\|sr\|ssr\|ur\|lr\|miss\|bluff\|secret` | 釣果を固定 |
| `?fast` | 待ち時間短縮 |
| `?go` | 自動開始+自動キャスト |
| `?win` | ファイト(連打・長押し・リズム)必勝 |
| `?secret` | シークレット魚を確実化 |
| `?mashneed=0.2` | 連打必要量を20%に(逃げ検証用) |
| `?rush=N` | RUSH N回転の状態で開始 |
| `?ending` | 開始時に通常EDを再生 |
| `?daycast=N` | その日の投数をNにして開始(29で次の1投で1日終了) |
| `?omen=N` | 海の気配ゲージをNで開始(100で満タン) |
| `?nushi` | 毎投ヌシに遭遇する |
| `?gold` | 釣れる魚を必ず金色個体にする |
| `?hold=N` | 保留の表示色を固定(0白/1青/2緑/3赤/4金/5虹)。激アツ・虹保留の見た目確認用 |
